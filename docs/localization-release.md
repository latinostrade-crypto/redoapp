# EN/RU — пакет игрового веб-приложения

Подготовлено 6 сентября 2026. Ветка: main. Изменения объединены в один
локальный коммит; push и deploy не выполняются при подготовке.

## Результат

- Переключатель EN/RU в меню аккаунта и в активных UNO, Poker и Blackjack.
- Язык сохраняется в redoapp_language, синхронизируется между вкладками;
  document.lang и язык TonConnect следуют выбранному языку игры.
- 863 сообщения в игровом каталоге, включая формы множественного числа.
  Переведены экраны, правила, задания, награды, статусы, подтверждения,
  типовые ответы сервера, результаты раздач и доступные описания элементов.
- Открытые сообщения хранят идентификаторы и параметры; смена языка не
  пересоздаёт игровую сессию и не повторяет действия/транзакции.
- Call/Fold/Check/Raise/All-in и команды Blackjack сохранены. Имена игроков,
  названия пользовательских турниров, адреса, коды, суммы и брендовые изображения
  не переводятся. Неизвестные диагностические ошибки показывают локализованное
  сообщение без предположений о причине; исходные ошибки остаются в обработчиках.
- Публичный сайт-комикс остаётся английским и без переключателя. Маршруты и
  каноническая Telegram-ссылка сохранены; game и story загружаются независимо.
- Устранены зависимости CSS от английских aria-label сейфа и наложение
  вспомогательных подписей кнопок Blackjack на мобильном экране.

## Проверки

Полный npm run prepare:release прошёл: TypeScript, frontend/server build,
traffic/SSE/persistence, маршруты, приватные комнаты, покерные фишки/анимации/
реакции/предварительные действия/side pots/resilience, правила Blackjack,
Daily Vault, рефералы, учёт билетов, PVP handoff, multiplayer, восстановление
казино, production auth и release manifest. После последних текстовых/мобильных
правок повторены lint, build, test:localization и финальный check:release.
Тест локализации добавлен в постоянный release gate.

Браузер: desktop 1280x900, mobile 390x844, узкий viewport 640x450;
профиль/события/магазин/PVP, сохранение RU после reload, отсутствие
нераскрытых параметров и горизонтального переполнения основных экранов.
В локальном покере смена языка сохраняет DOM, карты и performance.timeOrigin;
в Blackjack нет reload. UNO запускается с RU. Диалог ставки меняет язык без
пересоздания и сохраняет сумму. Сайт проверен с сохранённым RU: английский,
без переключателя, с исходной Telegram CTA.

API 500 из предыдущего прохода исчезли после запуска изолированного локального
backend. Финальный прогон основных экранов не получил ошибочных API-ответов.
Реальные выплаты и production-подключения не выполнялись. Узкий viewport —
проверка адаптации, а не утверждение о проверке каждого браузера на 200% zoom.
Существующее предупреждение lottie-web об eval остаётся без изменений.

## Состав пакета

Source, каталоги, package.json/lock, тесты, release gate и документация.
Список и SHA-256: output/release/manifest.json. Коммит/patch/bundle подготовлены
локально. Временные браузерные артефакты и пользовательские FOR AI материалы
не включены. Для отправки используется обычный git push после проверки коммита.
